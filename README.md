## ✨ Key Highlights & Features

- **🎮 Interactive 3D Cyber Desk Hero Scene**:
  - Fully articulated 3D desk environment with dynamic sunlight/moonlight, ambient occlusion, realistic reflections, and atmospheric bloom effects.
  - Interactive sector exploration: seamlessly navigate between the central desk, the **Development Journey**, and the **DSA Journey**.
  - Interactive day/night lighting modes toggled dynamically.

- **🏎️ Top-Down 3D Scroll Tracker**:
  - Orthographic Three.js 3D tracking car synchronized with page scroll depth, featuring dynamic wheel rotation physics and section snapping.

- **🚀 Compact Project Showcase Catalog**:
  - Modern browser mockup frames with multi-image carousels, responsive 3D parallax tilt, and interactive live demo / source code links.
  - Categorized tech stack pills (Frontend / Backend / AI / ML).

- **🏆 Bento-Grid Achievements & Leadership**:
  - Real-time animated number counters for algorithmic milestones (500+ DSA problems solved, contest rating, and open-source contributions).
  - Clean leadership role cards and single-click access to verified credential certificates on Google Drive.

- **📄 3D Interactive Floating Resume**:
  - 3D perspective document mockup with dynamic cast shadow physics and single-click verified PDF download.

- **🧭 Cyber Navigation Drawer**:
  - Tactile HUD menu with smooth waypoints to all sections.

- **⚡ Performance & Mobile Architecture**:
  - **Zero Frame Drops**: Smart render loop pausing (`frameloop="never"`) disables off-screen 3D WebGL computation when scrolling down to content sections.
  - **Lightweight Assets**: Optimized WebP asset pipeline reducing transfer payloads by >88%.
  - **100% Mobile Responsive**: Fluid layout across 360px–480px smartphones, tablets, and ultra-wide desktops.

- **Asset Optimization**: WebP image compression, Google Fonts (`Poppins`, `Quicksand`, `Share Tech Mono`)

## 🚀 Running Locally

Follow these steps to run the portfolio on your local machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Unnati1007/portfolio_uj.git
   cd portfolio_uj
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the project.

4. **Build for production**:
   ```bash
   npm run build
   ```
